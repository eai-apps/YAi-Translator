# YAi Translator

Переводчик, словарь и учебник немецкого языка в стиле Яндекс.Переводчика, Leo и Duolingo.
Сайт работает как обычное приложение (PWA): его можно установить на iPhone и Android.

**Языки:** немецкий ↔ русский, а также украинский и английский. Интерфейс — русский, немецкий или английский.

---

## Что уже работает (этап 1)

- **Перевод.** Два поля, выбор языков, автоопределение, кнопка обмена языками, умлауты `ä ö ü ß Ä Ö Ü`, голосовой ввод, озвучка, копирование, очистка. Перевод запускается сам через 600 мс после ввода.
- **Карточка слова.** Если введено одно слово: значения по смыслам, артикль (der — синий, die — красный, das — зелёный), множественное число, склонение по четырём падежам, спряжение глагола (Präsens, Präteritum, Perfekt, haben/sein), управление предлогами, примеры уровней A1–B2 с озвучкой, синонимы, антонимы и устойчивые выражения.
- **Фраза или текст.** Основной перевод и 2–3 альтернативы: нейтрально, разговорно, официально.
- **«Разобрать».** Объяснение грамматики на языке интерфейса: порядок слов, союзы, падежи, времена, типичные ошибки русскоязычных, слова из текста.
- **«Проверить мой немецкий».** Исправленный текст и объяснение каждой ошибки.
- **Словарь.** Поиск слова, избранное и история последних 50 переводов. Хранятся только в браузере, работают офлайн.
- **Профиль.** Язык интерфейса, светлая/тёмная/системная тема, свои бесплатные ключи Gemini и Groq (хранятся только на устройстве), установка приложения, состояние сервисов.
- **Ограничение бесплатного доступа.** Если общие ключи исчерпаны, появляется окно «Подключите свой бесплатный ключ» с пошаговой инструкцией и проверкой ключа.
- **PWA.** Установка на главный экран, офлайн-история и избранное.
- Вкладки «Учёба» и «Разговор» пока показывают экран «Скоро» — это следующие этапы.

## Технологии

Vite + React 18 + TypeScript (strict), Tailwind CSS, react-router-dom, i18next,
vite-plugin-pwa, Cloudflare Pages Functions, Cloudflare D1, Web Speech API.
Бюджет проекта — 0 €: только бесплатные тарифы Cloudflare, Google AI Studio и Groq.

## Быстрый запуск на компьютере

Нужны **Node.js 22 или новее** (минимум 20.19) и бесплатный аккаунт Cloudflare.

```bash
npm install
npm run icons     # один раз: создаёт PNG-иконки приложения
npm run dev       # сайт на http://localhost:5173
```

В этом режиме работает только интерфейс. Чтобы заработали переводы, во втором окне
терминала запустите бэкенд:

```bash
npm run build     # собирает папку dist
npx wrangler login
npm run dev:api   # API на http://localhost:8788
```

Сайт с `npm run dev` сам перенаправляет запросы `/api/*` на порт 8788.

> **Почему нужен `wrangler login`?** Cloudflare Workers AI (последний запасной сервис
> перевода) не умеет работать полностью локально. После однократного входа wrangler
> использует его через ваш аккаунт Cloudflare.

Полностью собранный сайт вместе с API можно посмотреть одной командой:

```bash
npm run preview   # сборка + локальный сервер на http://localhost:8788
```

### Локальная база данных

Чтобы кэш и счётчик запросов работали и на компьютере, создайте таблицы в локальной D1:

```bash
npx wrangler d1 create yai-translator-db
npx wrangler d1 execute yai-translator-db --local --file=./migrations/0001_init.sql
```

Команда `d1 create` покажет `database_id` — вставьте его в `wrangler.toml` вместо
`00000000-0000-0000-0000-000000000000`.

### Ключи сервисов

1. Скопируйте `.dev.vars.example` в `.dev.vars`.
2. Впишите бесплатные ключи:
   - **Gemini** — https://aistudio.google.com/apikey (кнопка «Create API key»);
   - **Groq** — https://console.groq.com/keys;
   - **DeepL** (необязательно, только обычный перевод) — https://www.deepl.com/pro-api
     (тариф «API Free»).
3. Перезапустите `npm run dev:api`.

Без ключей сайт всё равно запускается, но переводы будут отвечать окном
«Подключите свой бесплатный ключ». Свой ключ можно ввести прямо в этом окне или
в разделе «Профиль» — он сохраняется только в браузере и передаётся серверу
в заголовке запроса.

## Публикация на Cloudflare Pages

### Вариант 1: через GitHub (рекомендуется)

1. Создайте репозиторий на GitHub и загрузите в него папку проекта
   (без `node_modules`, `dist`, `.dev.vars` — они уже в `.gitignore`).
2. Откройте https://dash.cloudflare.com → **Workers & Pages** → **Create** →
   **Pages** → **Connect to Git** и выберите репозиторий.
3. Настройки сборки:
   - Framework preset: **Vite**;
   - Build command: `npm run build`;
   - Build output directory: `dist`;
   - Node version: **22** (переменная `NODE_VERSION=22`).
4. Создайте базу данных: в разделе **Workers & Pages → D1** нажмите
   **Create database**, имя `yai-translator-db`. Скопируйте `database_id`
   и вставьте его в `wrangler.toml` (или привяжите базу в настройках проекта,
   см. пункт 6).
5. Выполните миграцию **на настоящей базе**:
   ```bash
   npx wrangler d1 execute yai-translator-db --remote --file=./migrations/0001_init.sql
   ```
6. В проекте Pages откройте **Settings → Functions → Bindings** и проверьте:
   - D1 database: переменная **DB** → база `yai-translator-db`;
   - AI: переменная **AI**.
   Эти же привязки уже описаны в `wrangler.toml`; если Cloudflare подхватил их
   автоматически, ничего добавлять не нужно.
7. В **Settings → Variables and Secrets** добавьте секреты:
   `GEMINI_API_KEY`, `GROQ_API_KEY`, при желании `DEEPL_API_KEY`.
   Для каждого нажмите **Encrypt**.
8. Нажмите **Retry deployment** (или сделайте новый коммит). Сайт будет доступен
   по адресу вида `https://имя-проекта.pages.dev`.

### Вариант 2: из терминала

```bash
npm run build
npx wrangler login
npx wrangler pages project create yai-translator
npx wrangler pages deploy dist
```

Секреты для этого варианта:

```bash
npx wrangler pages secret put GEMINI_API_KEY --project-name yai-translator
npx wrangler pages secret put GROQ_API_KEY --project-name yai-translator
npx wrangler pages secret put DEEPL_API_KEY --project-name yai-translator
```

Не забудьте про миграцию D1 из пункта 5 — без таблиц `cache` и `usage`
переводы всё равно работают, но кэш и дневной лимит отключаются.

### Свой домен

В проекте Pages откройте **Custom domains → Set up a domain** и следуйте
подсказкам Cloudflare. Фронтенд ничего не знает о домене: адрес API берётся
из `VITE_API_BASE` (по умолчанию — тот же домен).

## Установка на телефон (PWA)

- **iPhone / iPad:** откройте сайт в **Safari** → кнопка «Поделиться» →
  **«На экран Домой»** → «Добавить».
- **Android:** откройте сайт в **Chrome** → меню ⋮ → **«Установить приложение»**.
- На компьютере в Chrome или Edge появится значок установки в адресной строке.

После установки приложение открывается без браузерной панели, а история,
избранное и настройки остаются на устройстве. Офлайн доступны история,
избранное и интерфейс; новые переводы требуют интернета.

## Как устроен проект

```
functions/            бэкенд Cloudflare Pages Functions
  api/                эндпоинты: translate, word, explain, check, health, key-test
  _lib/               провайдеры ИИ, цепочка, кэш, лимиты, промпты, проверка JSON
migrations/           SQL-схема D1 (cache, usage)
shared/               общие типы и список языков для фронта и бэка
src/                  React-приложение
  api/client.ts       все запросы к серверу — только здесь
  components/         кнопки, карточки, панели, карточка слова
  hooks/              тема, настройки, история, озвучка, перевод
  locales/            ru.json, de.json, en.json
  pages/              Перевод, Словарь, Учёба, Разговор, Профиль
scripts/              генератор иконок PWA
```

### Цепочка перевода

1. Кэш в D1 — одинаковый запрос не тратит лимиты.
2. Ключ пользователя из заголовков `X-User-Gemini-Key` / `X-User-Groq-Key`.
3. Общий ключ Gemini сайта.
4. Общий ключ Groq сайта.
5. DeepL API Free — только для обычного перевода.
6. Cloudflare Workers AI — последний запасной вариант.

Если не сработал никто, сервер возвращает `LIMIT_REACHED`, и сайт предлагает
подключить свой бесплатный ключ.

### Где менять настройки

- Модели ИИ, лимиты, таймауты, порядок провайдеров — `functions/_lib/config.ts`.
- Промпты — `functions/_lib/prompts.ts`.
- Список языков — `shared/languages.ts` (одна строка добавляет новый язык).
- Тексты интерфейса — `src/locales/*.json`.
- Задержка перевода, ключи localStorage, цвета артиклей — `src/config.ts`.

## Частые проблемы

**«Не удалось запустить remote proxy session».** Выполните `npx wrangler login`
один раз. Это нужно из-за Workers AI.

**Переводы не работают, появляется окно с ключом.** Не заданы ключи Gemini/Groq
или закончился дневной лимит. Введите свой ключ в окне или в «Профиле».

**`no such table: cache` в логах.** Не выполнена миграция. Локально:
`npx wrangler d1 execute yai-translator-db --local --file=./migrations/0001_init.sql`.
На сайте: та же команда с `--remote`.

**Микрофон не работает.** Голосовой ввод есть не во всех браузерах (лучше всего
Chrome и Safari) и требует разрешения на микрофон. На iOS голосовой ввод
работает только в Safari.

**Озвучка молчит.** В системе должны быть установлены голоса нужного языка;
в некоторых браузерах первый звук появляется только после клика по странице.

## Приватность

- История, избранное, тема, язык и ключи хранятся в `localStorage` браузера.
- Ключи пользователя не сохраняются на сервере: сервер читает их из заголовка
  запроса и никуда не записывает.
- В D1 попадают только кэш переводов и хеш IP для дневного счётчика.
- Тексты переводов отправляются выбранному сервису ИИ (Google, Groq, DeepL или
  Cloudflare) — без этого перевод невозможен.
