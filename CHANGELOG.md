# История версий

## 0.4.0 — 30.10.2026

Этап 3: 12 языков, «Как переводят другие», Lara Translate, резервные ключи, админка,
страница «О приложении». Логотип и логика аккаунтов не менялись.

### Добавлено

- **12 языков перевода:** к немецкому, русскому, украинскому и английскому добавились французский,
  испанский, итальянский, португальский, польский, нидерландский, турецкий и арабский.
  Список по-прежнему задаётся одной строкой в `shared/languages.ts`.
- **Арабский справа налево:** в `LanguageOption` появилось поле `rtl`; поле ввода, основной перевод,
  альтернативы и примеры получают `dir="rtl"`. Буквы U+0600–U+06FF определяются как арабский.
- **Определение языка для всех 12 языков** (`shared/detect.ts`): буквы `ñ ¿ ¡`, `ã õ ç`, `ł ą ę ś ź ż ń`,
  `ğ ş ı` и стоп-слова (15–28 на язык), турецкое `İ` учитывается с регистром.
- **Lara Translate** (`functions/_lib/classic/lara.ts`): REST API по документации и официальному SDK —
  подпись `Lara:<HMAC-SHA256>` для `POST /v2/auth`, затем `POST /v2/translate`. Ключи
  `LARA_ACCESS_KEY_ID` + `LARA_ACCESS_KEY_SECRET`.
- **Блок «Как переводят другие»** под основным переводом вместо кнопки «Сравнить переводчики»:
  до 300 символов загружается сам, длинный текст — по кнопке «Показать»; у каждого варианта
  «копировать», «озвучить» и «Использовать этот вариант». Сервис основного перевода не повторяется.
  Настройка «Показывать другие переводчики автоматически» в профиле (по умолчанию включена).
- **`/api/compare` кэширует каждый сервис отдельно** — падение одного не мешает кэшу остальных.
- **Резервные ключи:** у Gemini, Groq, DeepL, Microsoft, Google и Lara может быть несколько ключей
  (переменные `…_API_KEY_2 … _5` и ключи из админки). Ответ 429 → ключ «отдыхает» до 00:00 UTC,
  ответ 401/403 → помечается неверным. Состояние — таблица `key_state`, сам ключ там не хранится
  (только первые 12 символов SHA-256).
- **Админка `/admin`** (ленивая загрузка, доступ по секрету `ADMIN_LOGINS`):
  - «Обзор»: пользователи (всего/сегодня/7/30 дней, активные), уникальные посетители по хешу IP + дата,
    переводы за сегодня по сервисам, доля ответов из кэша, запросы ИИ, популярные языковые пары,
    график за 30 дней на SVG без сторонних библиотек;
  - «Ключи сайта»: источник, `••••1234`, состояние, «Проверить», «Добавить ключ» (с настоящей проверкой),
    «Удалить». Количество ключей на сервис не ограничено;
  - «Настройки»: дневной лимит ИИ на IP и баннер-объявление на ru/de/en;
  - «Пользователи»: логин, регистрация, последний вход, устройства, свои ключи, «Заблокировать», «Удалить»;
  - журнал действий (`admin_log`).
- **`GET /api/auth/me` отдаёт `isAdmin`**; ссылка «Админка» видна только админу.
- **Страница `/about`** с логотипом, описанием, версией, сервисами и историей версий
  (`src/data/changelog.ts`). Окно «Что нового» показывается один раз после обновления.
- **Счётчики статистики** в `/api/translate`, `/api/word`, `/api/explain`, `/api/check`, `/api/compare`;
  уникальные посетители отмечаются в `/api/health` (хеш «IP + день», сам IP не хранится).
- **Баннер-объявление** вверху сайта закрывается крестиком и больше не показывается.
- Новая миграция `migrations/0003_admin.sql`: `site_keys`, `key_state`, `stats_daily`, `visitors`,
  `admin_log`, `settings` и колонка `users.blocked`.

### Изменено

- `shared/types.ts` разгружен: типы админки вынесены в `shared/admin.ts` (по-прежнему доступны из `shared/types`).
- В профиле число языков и список сервисов обновлены: появился Lara Translate.
- Этапы 1–2 не затронуты: логотип, вход, сессии и шифрование ключей работают как раньше.

### Исправлено

- Заблокированный аккаунт получает `ACCOUNT_BLOCKED`, его сессии удаляются.
- Клиент API больше не отправляет тело запроса в GET (иначе браузер отклоняет запрос).

## 0.3.0 — 30.10.2026

Этап 2: аккаунт по логину и паролю, ключи ИИ в аккаунте, проверка сервисов сайта,
синхронизация избранного и истории. Логика перевода не менялась.

### Добавлено

- **Аккаунт без Google и Apple.** Логин (3–32 символа, латиница/цифры/`_.-`, регистр не важен)
  и пароль от 8 символов. Один логин работает на нескольких телефонах и компьютерах.
  Пароль хранится как PBKDF2-SHA256 (100 000 итераций) с солью 16 байт, сравнение — за постоянное время.
- **Сессии.** Токен 32 байта, в базе только SHA-256 от него; срок 90 дней с продлением.
  Cookie `yai_session` (HttpOnly; Secure; SameSite=Lax) для сайта и токен в теле ответа
  с `Authorization: Bearer` для будущих приложений.
- **Защита от подбора:** не больше 10 попыток входа и регистрации с одного IP за 15 минут
  (новый код `TOO_MANY_ATTEMPTS`, 429). Неверный логин и неверный пароль — одна ошибка.
- **Ключи ИИ в аккаунте:** AES-GCM, секрет `KEY_ENCRYPTION_SECRET`. Ключ проверяется настоящим
  запросом, сохраняется только рабочий. Клиенту возвращаются только последние 4 символа.
  Без секрета API отвечает `KEYS_STORAGE_DISABLED`, ключ хранится на устройстве, как раньше.
- **Ключи аккаунта работают везде:** `resolveUserKeys` берёт расшифрованные ключи пользователя из D1.
  Ключи из заголовков `X-User-*` по-прежнему важнее, дневной лимит сайта не тратится.
- **Новые эндпоинты:** `/api/auth/register`, `login`, `logout`, `logout-all`, `me`, `password`;
  `PUT`/`DELETE /api/keys/:provider`, `POST /api/keys/:provider/test`;
  `GET`/`PUT /api/sync`.
- **Проверка сервисов:** `GET /api/health?check=1` отправляет маленький настоящий запрос
  каждому настроенному сервису параллельно (таймаут 8 с), результат кэшируется в D1 на 10 минут.
- **Профиль:** карточки «Аккаунт → Мои ключи ИИ → Сервисы сайта → Настройки → Установка → О приложении».
  Мастер ключа за 3 нажатия (общий с окном лимита): кнопка «Получить бесплатный ключ»,
  три шага, «Вставить», автоматическая проверка, «Проверить ещё раз», «Удалить».
- **Синхронизация:** вошедший пользователь обменивается избранным и историей раз в минуту
  и после каждого изменения; побеждает более новая запись, удаления доходят до других устройств.
  Без входа всё работает как раньше — в localStorage.
- Новая миграция `migrations/0002_accounts.sql`: `users`, `sessions`, `user_keys`, `user_items`,
  `login_attempts`.

### Исправлено

- Список карточек профиля на телефоне больше не растягивает страницу по горизонтали.
- Текст о приватности ключей приведён в соответствие с реальностью (ключ может храниться в аккаунте).

## 0.1.0 — 30.10.2026

Первый этап: переводчик, словарь и учебник немецкого.

### Добавлено

- Экран перевода: автоопределение языка, обмен языками, умлауты, голосовой ввод,
  озвучка, копирование, очистка, перевод через 600 мс после ввода.
- Карточка слова: значения, цветной артикль, множественное число, склонение,
  спряжение, управление, примеры A1–B2, синонимы, антонимы, выражения.
- Альтернативные переводы фраз (нейтрально / разговорно / официально).
- Панели «Разобрать» и «Проверить мой немецкий».
- История (50 записей) и избранное в браузере, поиск по словарю.
- Профиль: язык интерфейса, тема, свои ключи Gemini и Groq, установка PWA.
- Окно подключения своего бесплатного ключа с пошаговым мастером.
- Бэкенд Cloudflare Pages Functions с цепочкой Gemini → Groq → DeepL → Workers AI.
- Кэш ответов и дневной лимит по IP в Cloudflare D1.
- PWA: manifest, service worker, иконки, офлайн-история.
- Локализация: русский, немецкий, английский.
- Экраны «Скоро» для «Учёбы» и «Разговора».

### Техническое

- Vite 7, React 18, TypeScript strict, Tailwind CSS, react-router-dom, i18next.
- Миграция D1 `migrations/0001_init.sql` (таблицы `cache`, `usage`).
- Строгая проверка JSON от ИИ и автоматическое переключение провайдеров.
- Генератор PNG-иконок без сторонних зависимостей.
