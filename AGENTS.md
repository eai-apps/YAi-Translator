Ты пишешь код проекта **YAi Translator**. Владелец проекта не программист, поэтому код потом будет проверять и дорабатывать другой ИИ (Claude). Пиши так, чтобы его было легко читать, проверять и менять.

## 1. Что это за продукт

Онлайн-переводчик, словарь и учебник немецкого в стиле Яндекс.Переводчика, Leo и Duolingo.

- Главная пара языков: **немецкий ↔ русский**. Также украинский и английский. Позже добавятся французский, испанский, итальянский и польский: список языков должен расширяться одной строкой в конфиге.
- Язык интерфейса: русский (по умолчанию), немецкий, английский.
- Темы: светлая, тёмная и «как в системе».
- Платформы: сайт на Cloudflare Pages (адрес `yai-translator.pages.dev`), PWA (установка на iPhone через Safari → «На экран Домой», на Android через Chrome). Позже из того же кода собираются приложения для Android и iPhone через Capacitor.
- **Бюджет — 0 €.** Только бесплатные тарифы и бесплатные API.

## 4. Правила кода (обязательно)

1. **Никаких заглушек.** Не оставляй `TODO`, `...`, «реализуйте сами», пустые функции и фейковые данные вместо реальной логики. Если что-то не успел, явно напиши об этом в `REPORT.md`.
2. Проект должен собираться без ошибок: `npm install` и `npm run build` проходят. Проверь это сам.
3. Один файл не длиннее ~250 строк. Если файл больше, раздели его.
4. Имена переменных и функций — на английском, понятные (`translateText`, а не `tt`). **Комментарии — на русском**, коротко объясняют, что делает блок.
5. Весь текст интерфейса берётся только через i18next (`t('key')`), никакого захардкоженного текста в компонентах. Все три файла языков заполнены полностью.
6. **Секреты никогда не попадают в код и в git.** Ключи только через переменные окружения Cloudflare (`GEMINI_API_KEY`, `GROQ_API_KEY`, `DEEPL_API_KEY`) и локально через `.dev.vars`.
7. Названия моделей ИИ, лимиты и URL сервисов хранятся только в `functions/_lib/config.ts`, чтобы их можно было поменять в одном месте.
8. Типы ответов API описаны в `shared/types.ts` и используются и на фронте, и на бэке.
9. Все ответы ИИ запрашиваются в **строгом JSON** по схеме из `shared/types.ts` и проверяются перед отдачей. Если JSON битый, повтори запрос или переключись на следующего провайдера.
10. Ошибки показываются пользователю понятным текстом на его языке, а не кодом ошибки.
11. Адаптивная вёрстка: телефон (от 360px), планшет, компьютер, телевизор. На телефоне снизу панель из 5 вкладок, на широком экране — меню слева.
12. Фронтенд не должен зависеть от того, что он открыт именно с pages.dev: адрес API берётся из `VITE_API_BASE` (пусто = тот же домен). Это нужно для будущих приложений на Capacitor.

## 5. Логика перевода (обновлено Claude, версия 0.2.0)

**Главное правило: сначала обычные переводчики, ИИ — только по кнопке.**

- `/api/translate` с `mode: 'classic'` (по умолчанию): кэш D1 → DeepL → Microsoft → Google → MyMemory → M2M100
  (папка `functions/_lib/classic/`, порядок в `CLASSIC.order`). Пользователь может выбрать конкретный сервис (`provider`).
  ИИ включается, только если все обычные переводчики молчат.
- `/api/translate` с `mode: 'ai'` — кнопка «Спросить у AI»: ключ пользователя → Gemini → Groq → Workers AI, с альтернативами.
- `/api/compare` — один текст во всех подключённых обычных переводчиках сразу.
- `/api/word` — полная карточка для 1–3 слов (ИИ). Кэшируется на год, поэтому каждое слово стоит ИИ один запрос на всех.
- `/api/explain`, `/api/check` — только ИИ, только по кнопке.
- Дневной лимит по IP действует только на общие ключи ИИ (`createLimitGuard` → `beforeShared`). Обычные переводчики его не тратят.
- Таблицы D1 создаются автоматически (`functions/_lib/schema.ts`). Новые таблицы добавляй и туда, и в `migrations/`.
- Модели Gemini: только 3.x (2.5 не выдаются новым ключам). DeepL: ключ только в заголовке `Authorization`.

### Этап 1 — переводчик (ГОТОВО, версия 0.2.0)

- Экран «Перевод»: два поля, выбор языков, кнопка ⇄, автоопределение языка, строка умлаутов `ä ö ü ß Ä Ö Ü` над полем ввода, кнопки «озвучить», «копировать», «очистить», голосовой ввод, перевод с задержкой 600 мс после ввода.
- Если введено **одно слово**: карточка слова — варианты перевода по смыслам, артикль с цветом (der синий, die красный, das зелёный), множественное число, таблица склонения по 4 падежам; для глагола — спряжение (Präsens), Präteritum, Perfekt с haben/sein, управление предлогами; примеры предложений по уровням A1, A2, B1, B2 (с переводом и озвучкой); синонимы, антонимы, устойчивые выражения.

- История последних 50 переводов и «Избранное» пока хранятся локально в браузере (localStorage, с try/catch).
- Профиль и настройки: язык интерфейса, тема, свой ключ Gemini и Groq (хранится только на устройстве).
- PWA: manifest, иконки, установка на iPhone и Android, офлайн-режим для истории и избранного.
