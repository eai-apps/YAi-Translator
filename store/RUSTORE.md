# Чек-лист публикации YAi Translator в консоли RuStore

Инструкция для владельца по публикации приложения в магазине RuStore.

---

## 1. Вход и создание приложения
1. Откройте консоль разработчика RuStore: https://console.rustore.ru/
2. Авторизуйтесь под своей учётной записью разработчика.
3. В правом верхнем углу нажмите **«Добавить приложение»**.
4. Введите название: **YAi Translator**.
5. Выберите платформу: **Android** (приложение также оптимизировано для **Android TV**).

---

## 2. Основная информация о приложении
- **Название:** `YAi Translator`
- **Категория:** `Образование` → `Изучение языков` (или `Образование`)
- **Краткое описание (до 80 символов):**
  > `YAi Translator — онлайн-переводчик, умный словарь и карточки для учёбы`
- **Полное описание:**
  Скопируйте текст из файла `store/DESCRIPTIONS.md` (раздел «1. Русский язык»).
- **Ключевые слова (теги):**
  `переводчик, словарь, немецкий язык, английский язык, грамматика, карточки, слова, behorde, обучение, офлайн, артикли, спряжение, склонение, anki, разговорник`

---

## 3. Графические материалы
Все материалы находятся в репозитории в папке `store/`:

1. **Иконка приложения:**
   - Файл: `store/icon-512.png`
   - Требования RuStore: PNG 512×512 px, до 2 МБ, без прозрачного фона.

2. **Скриншоты для смартфона (разрешение 1080×1920 px):**
   - Файлы из папки `store/screenshots/`:
     1. `phone_01_translate.png` — Главный экран перевода (DE↔RU, параллельные переводчики).
     2. `phone_02_card.png` — Карточка слова (артикли, склонение, формы, примеры A1–B2).
     3. `phone_03_study.png` — Учёба и интервальное повторение (32 колоды, тренировки, экспорт в Anki).
     4. `phone_04_phrasebook.png` — Разговорник по темам с озвучкой.
     5. `phone_05_letter.png` — Помощник по письмам из Behörde (сроки, отправитель, суть).
     6. `phone_06_dialog.png` — Двусторонний диалог двух собеседников с переворотом 180°.
     7. `phone_07_grammar.png` — Справочник грамматики немецкого и английского.
     8. `phone_08_offline.png` — Надежная офлайн-работа без подключения к интернету.

3. **Материалы для Android TV (если выбран показ на ТВ):**
   - **Баннер для ТВ:** `store/tv-banner-1280x720.png` (1280×720 px).
   - **Скриншоты для ТВ:** `store/screenshots/tv_01_translate.png`, `store/screenshots/tv_02_dictionary.png` (1920×1080 px).

## 4. Возрастной рейтинг и классификация
1. Перейдите во вкладку «Возрастной рейтинг».
2. Пройдите короткий опросник:
   - Насилие, ненормативная лексика, азартные игры, алкоголь: **Нет**.
   - Сбор персональных данных для рекламы: **Нет**.
   - Пользовательский контент / открытый чат: **Нет**.
3. Итоговый рекомендуемый рейтинг: **3+** или **6+**.

## 6. Загрузка сборки (APK)
1. Скачайте подписанный релизный APK-файл из GitHub Releases:
   https://github.com/eai-apps/YAi-Translator/releases/latest/download/YAi-Translator.apk
2. Либо запустите сборку вручную через GitHub Actions:
   GitHub → репозиторий `eai-apps/YAi-Translator` → вкладка **Actions** → **Build Android APK** → **Run workflow**.
3. В консоли RuStore загрузите файл `YAi-Translator.apk`.
4. Проверьте параметры сборки:
   - Имя пакета (Package name): `app.yai.translator`
   - Код версии (Version code): `5`
   - Номер версии (Version name): `1.0.0`
   - Поддерживаемые архитектуры: `Universal` (ARM64, ARMv7, x86, x86_64)

---

## 7. Отправка на модерацию
1. Нажмите **«Сохранить черновик»** и проверьте предпросмотр карточки.
2. Нажмите **«Отправить на модерацию»**.
3. Проверка в RuStore обычно занимает от 2 до 24 часов.
