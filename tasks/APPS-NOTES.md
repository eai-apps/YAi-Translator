# Заметки владельца к этапу приложений (Android / iOS) — НЕ делать, пока не попросят

## Android: один универсальный APK
- Один файл для телефонов, планшетов и **Android TV** (не отдельные версии).
  - В манифесте: `LEANBACK_LAUNCHER` + обычный `LAUNCHER`; `android.software.leanback` и `android.hardware.touchscreen`
    с `required="false"`; баннер 320×180 для экрана TV.
  - Управление пультом (D-pad): видимый фокус у всех кнопок, вкладок, чипсов и полей; на TV — ввод голосом (микрофон пульта).
  - Без нативных библиотек под отдельные процессоры — один APK на все устройства.
- **Android Auto / CarPlay:** переводчики туда не пускают (в машине разрешены только аудио, навигация, сообщения,
  зарядка, парковка). Не делать; при желании — позже «озвучка перевода» через обычный Bluetooth.

## Обновление «по воздуху» (как в SlyNet Radio)
1. **Содержимое приложения** (экраны, тексты, исправления) — обновляется само, без новой установки:
   приложение при запуске сверяет версию с сайтом и подтягивает новую сборку (Capacitor live-update, свой сервер —
   Cloudflare Pages / GitHub Releases, без платных сервисов). Если сеть есть — новая версия при следующем открытии.
2. **Сам APK** (когда меняется нативная часть) — файл `version.json` на сайте: `{ versionCode, versionName, apkUrl,
   notes_ru/de/en, required }`. Приложение сравнивает, показывает «Доступна версия X — Обновить», скачивает APK
   (GitHub Releases) и открывает установщик Android (одно нажатие «Установить» — так требует Android).
   Сборка APK — GitHub Actions по тегу `v*`, подпись одним и тем же ключом (ключ — в секретах GitHub, не в коде).
3. **Версии для магазинов:** у Google Play своё обновление через магазин (Play In-App Updates), самообновление APK
   и разрешение `REQUEST_INSTALL_PACKAGES` там **выключены** (Google такое запрещает). У RuStore — так же через магазин.
   Сайт/APK с сайта — полное самообновление. Переключатель сборки — `VITE_STORE` (см. этап 7, п. 7).
