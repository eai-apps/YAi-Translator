# План до завершения проекта — части 14–21 для Antigravity

Написал Claude 01.11.2026. Владелец отдаёт Antigravity **по одной части**: текст для вставки — в конце каждой части
(блок «Промпт»). Claude потом проверяет все части по журналу в `HANDOFF.md` и отчёту в `REPORT.md`.

## Общие правила для КАЖДОЙ части (читать перед любой частью)

1. Перед работой прочитай `HANDOFF.md` (правила, решения, журнал) и `AGENTS.md`. После работы — запись в «Журнал работ»
   в `HANDOFF.md` (дата, кто, часть, **полный список изменённых/созданных файлов**, что проверено, что не успел).
   Отчёт части — в начало `REPORT.md` (новые сверху).
2. Git на компьютере нет — ничего не коммить. Claude сам заберёт файлы, проверит и выложит.
3. **Не трогать:** `android/` (кроме части 21), `capacitor.config.ts`, `src/api/request.ts`, `src/lib/liveUpdate.ts`,
   `functions/_lib/prompts.ts`, `deeplUrl()`, `database_id`, `KEY_ENCRYPTION_SECRET`, `schemaReady`, логотип,
   `.github/`. Не возвращать скрытие клавиатуры по событию `scroll` (ломает iPhone).
4. Все тексты интерфейса — через i18next, ключи **ru/de/en одинаковые** (проверь скриптом подсчёт ключей).
5. Tailwind: цвета — CSS-переменные; прозрачности (`bg-soft/50`, `border-accent/30`) **не работают** — не используй.
6. Пакеты — только с registry.npmjs.org. Никаких платных сервисов и ключей. Только бесплатное.
7. **Лицензии баз данных обязательны.** Бери только открытые (CC-BY, CC-BY-SA, CC0, MIT, Apache, LGPL, ODbL).
   Каждую базу — в `public/licenses.json` и на страницу «О приложении» → блок «Источники данных»
   (название, ссылка, лицензия, автор). Не брать: словари Duden/PONS/Langenscheidt/Collins/Oxford,
   списки Goethe-Institut, Yandex/Google API, скачанные с сайтов тексты без лицензии.
8. **Ограничения Cloudflare Pages:** не больше 20 000 файлов в сайте и не больше 25 МБ на файл. Базы режь на куски
   (как `public/lex/de/<2 буквы>.json`), каждый кусок желательно < 300 КБ. Сырые скачанные дампы — только в
   `scripts/<что-то>/cache/` (добавь в `.gitignore`), в сайт — только готовые куски. Общий размер `public/`
   после всех частей — не больше ~150 МБ. В отчёте пиши, сколько файлов и МБ добавлено.
9. Скрипты сборки баз — в `scripts/`, с понятным `npm run …`, повторяемые (скачал → разобрал → нарезал).
   Скачивание — внутри скрипта, с кэшем; если сеть не работает — понятная ошибка.
10. Всё должно работать **офлайн и мгновенно** для того, что лежит в базах, и не ломать сайт без этих баз.
11. Проверка в конце каждой части: `npx tsc -p tsconfig.app.json --noEmit`, `npx tsc -p tsconfig.functions.json --noEmit`,
    `npm run build` без ошибок; вручную в браузере — ширина 390 px (телефон) и ПК; тёмная и светлая тема.
12. Версия: поднять в `package.json`, `src/config.ts` (APP_VERSION), `functions/_lib/config.ts`, `public/version.json`
    (versionName; `versionCode` не трогать до части 21), `src/data/changelog.ts` (ru/de/en), `CHANGELOG.md`.
13. Если задача части слишком большая — сделай главное полностью и аккуратно, остальное перечисли в «не успел».
    Лучше меньше, но рабочее.

## Часть 14 — Словари для всех языков, а не только немецкого (0.16.0)

**Цель:** всё, что сейчас умеет немецкий (мгновенная карточка, «Слова из словаря» под переводом, подсказки при
наборе, «+ В учёбу»), работает для **английского** и других языков приложения: ru, uk, en, fr, es, it, pt, pl, nl, tr
(ar — по возможности). Плюс настоящие переводы слов из базы, а не короткий ручной список `commonTranslationsDeRu.ts`.

**Источник:** Wiktextract / kaikki.org (данные Викисловаря, лицензия CC-BY-SA 4.0 + GFDL) —
`https://kaikki.org/dictionary/` → по языку файл «All senses»/«All words» JSONL. Наш парсер уже есть:
`scripts/lexicon/kaikki-parser.mjs`, `generator.mjs`, `build-lexicon.mjs` (сейчас только de).

1. Обобщи генератор: `npm run lexicon -- --lang en` (и `--lang all`). Для каждого языка — `public/lex/<lang>/<2 буквы>.json`
   в том же формате, что de (часть речи, род/артикль если есть, мн. число, формы, IPA, ссылки форма → лемма).
2. **Переводы слов:** из секции `translations` kaikki вынимай переводы на ru, de, en, uk (только эти 4 — иначе база
   разрастётся). Поле `tr: { ru: [...], de: [...], en: [...], uk: [...] }`, до 4 вариантов на язык, первые — самые
   частые/первые по порядку значений. Перевод для «Слова из словаря» и карточек брать отсюда; `commonTranslationsDeRu.ts`
   оставить как запасной вариант.
3. Ограничь размер: только слова с переводом или с частотой (см. часть 15) — ориентир до 60 000 лемм на язык для
   en/de/ru, до 25 000 для остальных. Формы — только ссылками на лемму.
4. Обобщи `useLexicon.ts` / `lookupLexicon(word, lang)`: правила форм — по языку (en: -s, -es, -ed, -ing, -ies→y,
   неправильные глаголы went→go, children→child; ru/uk: по формам из kaikki; романские: -s/-es; остальные — только
   формы из базы). Немецкие правила оставить как есть.
5. `useConnectedWords(text, lang)` — для языка исходного текста и языка перевода (показывать слова того языка,
   который **не родной** для пользователя: если перевод ru→en — английские слова перевода; если en→ru — английские
   слова исходного текста). Стоп-слова — по языку (`src/data/stopwords/<lang>.ts`, источник — открытый список
   stopwords-iso, MIT: https://github.com/stopwords-iso).
6. Карточка слова (`InstantWordCard`, `WordDetailModal`) — показывает данные для любого языка: без артикля, если
   у языка нет рода; для en — британское/американское IPA, если есть.
7. **Мгновенная карточка без ИИ — для всех языков и направлений** (как сейчас «Какашка» → «DIE Kacke — какашка»,
   см. `WordPanel.tsx`: `translatedText`, `useTranslationWord`, `InstantWordCard` prop `meaning`). Правило: в базе
   ищется слово на «изучаемом» языке — исходное, если перевод С него, или перевод, если перевод НА него;
   значение — второе слово. Для en, ru, uk, fr, es… так же, как для de. ИИ-разбор по-прежнему по кнопке
   «Разбор слова от ИИ» (режим из админки/профиля — `src/lib/aiCardMode.ts`, не ломать).
8. Учёба: «+ В учёбу» сохраняет язык слова; колода «Из переводов» — отдельная для каждого языка
   («Из переводов · English»).

**Проверка:** перевести «I went to the shops with my children» → под переводом чипы go · идти, shop · магазин,
child · ребёнок; «Ich ging…» по-прежнему работает; русский текст «я купил книги» при переводе ru→en показывает
английские слова перевода.

**Цель:** карточка слова как в хорошем словаре — для de, en и ru в первую очередь, остальные — что найдётся.

Источники (все бесплатные и открытые):
- **Примеры предложений с переводом:** Tatoeba (CC-BY 2.0 FR) — https://tatoeba.org/downloads
  (`sentences.tar.bz2`, `links.tar.bz2`, `sentences_with_audio`). Пары de↔ru, en↔ru, de↔en, uk↔ru и др.
  Нарежь: для каждой леммы до 5 коротких предложений (≤ 12 слов) с переводом на ru/de/en.
  Файлы `public/ex/<lang>/<2 буквы>.json`. Указывать «Tatoeba, CC-BY» и id предложения.
- **Частота:** FrequencyWords (Hermit Dave, по OpenSubtitles, MIT/CC-BY-SA) — https://github.com/hermitdave/FrequencyWords
  → ранг слова (`fr` в базе лексикона). По рангу — примерный уровень: ≤1000 A1, ≤2000 A2, ≤4000 B1, ≤8000 B2, иначе C1+.

- **Синонимы:** немецкий — OpenThesaurus (LGPL) https://www.openthesaurus.de/about/download;

- **Произношение (аудио):** Lingua Libre / Wikimedia Commons (CC-BY-SA) — в kaikki есть поле `sounds` с mp3/ogg

  запись человека — играть её, иначе — синтез речи (уже есть).
- **Немецкие глаголы:** сильные/неправильные формы (Präteritum, Partizip II, haben/sein) — из kaikki
  `forms`; таблица спряжения в карточке (уже частично есть — дополнить из базы, без запроса к серверу).

1. Добавь в карточку блоки: «Примеры» (с переводом, кнопка 🔊 у предложения), «Уровень ~A2», «Синонимы»

2. В горизонтальной карусели карточки (мобильный) — те же блоки как отдельные слайды.
3. «Слово дня» — брать из частотных A1–B1 слов с примером, а не случайное.

## Часть 15Б — Полная карточка слова БЕЗ ИИ: как раньше, но из базы (0.17.5)

**Решение владельца (01.11.2026):** карточка слова ВСЕГДА должна быть полной, как раньше у ИИ — примеры по уровням

ИИ-разбор остаётся по кнопке «Разбор слова от ИИ» (`src/lib/aiCardMode.ts`, `WordPanel.tsx` — не ломать).

Как этого добиться (всё бесплатно):

1. **Одна карточка на немецкое (английское…) слово, для обоих направлений.** Сейчас кэш карточки привязан к
   направлению: «Kacke» de→ru и «Какашка» ru→de — две разные записи, и прогретые карточки при ru→de не находятся.
   Сделай ключ карточки: `лемма на изучаемом языке + язык объяснений (ru/de/en/uk)`. При переводе ru→de карточка
   берётся по немецкому переводу (уже так ищется мгновенная карточка: `WordPanel.tsx`, `translatedText`,
   `useTranslationWord`). Сервер `/api/word`: если пришло русское слово при target=de — сначала искать готовую
   карточку немецкого перевода.
2. **Вечный склад готовых карточек.** Каждая карточка, которую хоть раз сделал ИИ (любому пользователю), сохраняется
   навсегда в D1 (таблица `word_cards`: lemma, lang, explain_lang, card_json, provider, updated_at) и дальше выдаётся
   всем бесплатно, без лимита. Кнопка в админке «Пересоздать карточку».

   (готовые карточки топ-слов), приложение и сайт читают их без сервера и без сети. Помни лимиты Pages
   (20 000 файлов, 25 МБ на файл).
5. **Если готовой карточки нет — собрать полную карточку из открытых баз, без ИИ**, тем же видом, что ИИ-карточка
   (те же вкладки/карусель `WordCard.tsx`), с пометкой «из словарей»:
   - **склонение существительного** — полная таблица 4 падежа × ед./мн. число с артиклями (из kaikki `forms`,
