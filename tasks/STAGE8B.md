## 1. Расположение на компьютере (широкий экран, `lg:` и шире)

Сейчас слева поле ввода, справа перевод и «Как переводят другие», а **под полем ввода пустое место**. Сделать так:
- **Левая колонка:** поле ввода → **сразу под ним блок перевода** (основной перевод, «Ещё варианты», кнопки).
- **Правая колонка:** «Как переводят другие» и **перевод ИИ** (блок «Показать перевод AI» / его результат) — на всю высоту.
- Пустых дыр быть не должно: колонки идут сверху вниз независимо (`flex flex-col gap`, а не одна общая сетка по строкам).
- На телефоне порядок: поле ввода → перевод → «Как переводят другие» → карточка слова.

## 2. Перевод у каждого связанного слова

Во вкладке «Связанные слова» (и в ленте «Всё») рядом с каждым синонимом, антонимом и однокоренным словом —
**короткий перевод** серым: `bringen — приносить`, `besorgen — раздобыть`, `abholen — забрать`, `die Abholung — получение`.
- В промпт карточки (`prompts.ts`) — новое поле `"glossary": {"слово": "перевод", …}`: перевод на язык цели **для каждого**
  слова из `synonyms`, `antonyms`, `family` (одно-два слова). Валидатор: только строки, до 40 пунктов.
- Для синонимов из OpenThesaurus, которых нет в `glossary`, — без перевода (не выдумывать).
- Чипс по-прежнему нажимается и переводит слово; перевод — мелким текстом внутри чипса или под ним, аккуратно.
- Поднять `PROMPT_VERSION`.

## 3. Вкладка «Грамматика» — подробно и с примерами

Сейчас там 3–4 общие фразы. Нужно как в хорошем учебнике:
- Новое поле ИИ `"grammar": [{ "title", "explanation", "examples": [{ "level", "text", "translation" }] }]` — 3–5 пунктов
  про ЭТО слово, на языке интерфейса. Для глагола: какой падеж управляет (с предложениями: «Ich hole **den** Koffer» — Akk.),
  возвратная форма (`sich etwas holen` + пример), приставки (`abholen`: «Ich hole dich **ab**» — приставка уходит в конец),
  Perfekt с haben/sein («Ich **habe** das Buch **geholt**»), Präteritum в рассказе. Для существительного: род и почему,
  мн. число, n-склонение, предлоги. Для прилагательного: окончания с der/ein/без артикля, степени сравнения.
- У каждого пункта 2–4 примера уровней **A1 / A2 / B1 / B2**, искомое слово в примере подсвечено, предложение нажимается
  (переводится), у каждого 🔊.
- Названия тем (Akkusativ, Perfekt…) остаются ссылками на справочник (`GrammarLinkedInline`), внизу — «Темы по этой грамматике».
- Старое поле `grammarNotes` оставить для совместимости (кэш), показывать, только если нет `grammar`.

## 4. Примеры: «Как ещё сказать»

Во вкладке «Примеры» после уровней A1–B2 и «Из жизни» добавить фильтр **«Как ещё сказать»**: 3–4 пары «то же самое другими
словами» (поле ИИ `"paraphrases": [{ "text", "translation" }]`, например «Ich hole das Buch» → «Ich bringe das Buch mit»).

## 5. Словарь (страница `/dictionary`) — для любого языка

- Подсказка в поле и в пустом блоке: «Введите слово на любом языке…» (не «немецкое»). Рядом — выбор языка слова
  («Определить» по умолчанию) и языка перевода, как на экране перевода (компактно).
- Поиск работает для любого из 12 языков (передавать выбранный язык в `/api/word` и `/api/dict`).

## 6. Свои списки слов («Мои списки»)

Как плейлисты: человек сам собирает слова для учёбы.
- В «Учёба» — плитка **«Мои списки»** → страница `/learn/lists`: создать список (название, необязательный значок-эмодзи),
  переименовать, удалить; внутри — слова списка, «Учить этот список» (повторение только этих карточек) и упражнения по списку.
- Кнопка **«В карточки»** в карточке слова и в блоке перевода становится с маленькой стрелкой `▾`: «В карточки» / «В список…»
  (выбор существующего или «+ Новый список»). Из «Избранного» и «Истории» — то же меню у каждого слова.
- Слово может быть в нескольких списках; список хранит id карточек. Хранение — как у карточек: localStorage, у вошедших —
  синхронизация (`study_lists` в D1 по образцу `study_cards`, лимит 100 списков на аккаунт).
- Дизайн — спокойный, без лишнего: карточки списков с названием и числом слов, как плитки на экране «Учёба».

## 7. Боковое меню на компьютере

Внизу меню «О приложении» и строка с версией обрезаются на невысоких экранах. Сделать меню прокручиваемым
(`overflow-y-auto` у списка), переключатели темы и языка — компактнее (в одну строку иконками), версия всегда видна.
