# Задание: этап 7 — платные нейросети по ключу и бонусы за регистрацию (версия 0.8.0)

Делать **только после того, как Claude проверил этап 6.** Сначала прочитай `AGENTS.md` и `REPORT.md`.

**Не трогай:** логотип; `functions/_lib/auth/*` (только переиспользуй `encryptKey` / `decryptKey`); `deeplUrl()`;
`schema.ts` — только добавляй таблицы и колонки в конец, флаг `schemaReady` не меняй; `vite.config.ts`, `src/main.tsx`,
`pick.tsx`. **Проверки в браузере НЕ делай** — только сборка, типы и запросы к API на локальном `wrangler pages dev`.

Цель: кроме бесплатных Gemini и Groq, сайт умеет работать с **любой нейросетью по платному ключу** — как в проекте
«Мозги для колонки»: OpenRouter (один ключ — сотни моделей) или ключ, купленный у продавца (свой адрес API + ключ).
Админ включает самые дешёвые модели как **платную подстраховку для всего сайта**, а пользователь может подключить
свой платный ключ в профиле. Плюс понятные бонусы за регистрацию.

---

## 1. Провайдер «Платная нейросеть» (OpenAI-совместимый)

- Новый провайдер `paid` в `functions/_lib/providers/paid.ts`: запрос `POST {baseUrl}/chat/completions`
  с `Authorization: Bearer <key>`, `model`, `messages`, `response_format: {type:"json_object"}` (если модель не поддерживает —
  повтор без него), таймаут как у Groq. Из ответа берём `choices[0].message.content` и `usage.total_tokens`.
- Подключение (`connection`) = `{ id, name, baseUrl, key (зашифрован), models: [{id, enabled, priceIn, priceOut}], order }`.
  Таблица `paid_connections`, ключ шифруется `encryptKey` с контекстом `site:paid:<id>`.
- Готовые адреса в подсказке: OpenRouter `https://openrouter.ai/api/v1`; «свой продавец» — адрес вводится вручную
  (`https://…/v1`). Проверка адреса: только `https://`, без IP-адресов и `localhost`.
- **Список моделей:** кнопка «Загрузить модели» → `GET {baseUrl}/models`. Если в ответе есть цены (`pricing.prompt`,
  `pricing.completion` у OpenRouter) — показываем цену за 1 млн токенов, сортируем **от дешёвых**. Только текстовые
  модели для чата; «думающие» и большие (pro, opus, o1, reasoning, -thinking) помечаем 🐢 «медленно и дорого».
- **Проверить модель:** короткий запрос «Hallo → ru» — ✅ и время ответа, или понятная причина ошибки
  (неверный ключ / нет денег на балансе / модель недоступна / не успела).
- **Баланс:** для OpenRouter — `GET https://openrouter.ai/api/v1/credits` (остаток в долларах, сверь формат с документацией
  https://openrouter.ai/docs — **не выдумывай поля**; если не получилось — показывай «Остаток смотрите на сайте продавца»).

## 2. Админка → новая вкладка «Нейросети»

- Список подключений: название, адрес, `••••1234`, баланс, кнопки «Модели», «Проверить», «Удалить».
- Экран «Модели»: галочки «включить», цена, 🐢, кнопка «Проверить» у каждой, стрелки порядка. Включённые модели
  пробуются по очереди сверху вниз.
- **Порядок ИИ для всего сайта** (радиокнопки): «Сначала бесплатные (Gemini → Groq), потом платные, потом Cloud AI»
  (по умолчанию) / «Сначала платные» / «Платные выключены».
- **Бюджет платных:** лимит токенов в день на весь сайт (по умолчанию 50 000) и в месяц (по умолчанию 1 000 000).
  Счётчики в `stats_daily` (`paid_tokens`). Достигнут лимит — платные пропускаются до завтра / следующего месяца.
  На вкладке «Обзор» — «Платные токены: сегодня N / за месяц M из лимита».
- **«Платные — только для зарегистрированных»** (галочка, по умолчанию включена).
- Ссылки «Где купить ключ» (редактируемый список: название, адрес, короткое описание) — показываются пользователям
  в профиле. Начальный пункт: OpenRouter (https://openrouter.ai, оплата картой, один ключ на сотни моделей).

## 3. Цепочка ИИ (`router.ts`)

- Порядок по настройке из п. 2: личные ключи пользователя (Gemini, Groq, свой платный) → общие бесплатные →
  общие платные (если разрешены этому пользователю и бюджет не исчерпан) → Cloud AI (Workers AI).
- `runJsonTask` получает `isRegistered: boolean`; общие платные — только при `isRegistered`, если галочка включена.
- После успешного ответа платной модели — прибавить `usage.total_tokens` к счётчикам. Ошибка 401/402/403 —
  подключение помечается «нет денег / неверный ключ» (как `key_state`), и оно пропускается до проверки админом.
- Не ломай `personalOnly` и `only` — их использует выбор «Gemini — мой ключ» в списке переводчиков.

## 4. Свой платный ключ у пользователя (профиль)

- В профиле → «Ключи ИИ» — третий пункт **«Платная нейросеть»**: адрес API (подсказка: OpenRouter или адрес продавца),
  ключ, кнопка «Загрузить модели» → выбор одной модели (от дешёвых), «Проверить».
- Хранится как остальные ключи: в аккаунте зашифрованным или только на устройстве (заголовки `X-User-Paid-Url`,
  `X-User-Paid-Key`, `X-User-Paid-Model`). Сервер ключ не логирует.
- В списке переводчиков (`ProviderSelect`) появляется пункт **«<модель> — мой ключ»**, как сейчас у Gemini/Groq
  (`PERSONAL_AI_CHOICES` — добавь `paid`, логика `personalOnly` уже есть в `router.ts`).
- Блок **«Где купить ключ»** со ссылками из админки и короткой инструкцией (как в «Мозгах для колонки»):
  1) купить ключ или пополнить OpenRouter; 2) если продавец прислал только код — найти на его сайте адрес API
  (Base URL) и сам ключ; 3) вставить сюда адрес и ключ; 4) «Загрузить модели» → выбрать быструю и дешёвую
  (flash, mini, haiku, fast). Подпись: «Вы покупаете ключ сами напрямую у продавца, мы ничего не получаем».

## 5. Бонусы за регистрацию (всё настраивается в админке → «Настройки»)

| | Гость | Зарегистрированный |
|---|---|---|
| Обычные переводчики | без ограничений | без ограничений |
| ИИ-функции на общих ключах (перевод AI, «Разобрать», «Проверить», «Спросить у AI», грамматика) | N в день (по умолчанию 5) | M в день (по умолчанию 50) |
| Общие платные нейросети | нет | да (если включено) |
| История переводов | 50 последних, только на устройстве | 1000, на всех устройствах |
| Избранное и карточки | на устройстве | на всех устройствах |

- Настройки: «Лимит ИИ для гостей», «Лимит ИИ для зарегистрированных», «ИИ только после входа» (галочка: гость вообще не
  получает ИИ на общих ключах, видит «Войдите, чтобы пользоваться ИИ бесплатно»). Личный ключ работает всегда и без входа.
- Окно лимита (`LimitDialog`) для гостя показывает сначала **«Зарегистрироваться — 50 запросов в день»**, потом «Свой ключ».
- `AUTH.maxSyncItemsPerUser` и размер истории — из настроек; локальная история гостя — 50.
- На странице «Профиль» у гостя — карточка «Что даёт регистрация» (таблица выше, коротко).
