## 5. Словарь без ИИ для гостей (важно владельцу)

Гость без лимита ИИ видит карточку «Словари — без ИИ». Для «цветок» (ru→de) там сейчас английские толкования
«flower (plant that bears flowers)» — бесполезно. Нужно:
- Для слова **не на немецком** при переводе на немецкий брать **ru.wiktionary.org** (раздел «Перевод» → «Немецкий»:
  слова с родом, например `Blume f` → «die Blume»), затем для главного немецкого слова — данные **de.wiktionary**
  (артикль, мн. число, склонение, примеры) — уже есть в `functions/_lib/dict/wiktionaryDe.ts`.
- Значения показывать на языке интерфейса; английские толкования при интерфейсе ru/de не показывать.
- Примеры — Tatoeba ru↔de (уже есть `tatoeba.ts`), синонимы — OpenThesaurus для немецкого слова.
- Итог для «цветок»: «die Blume», «die Blüte» с переводом, род, мн. число, склонение, 3–5 примеров. Для «работа» —
  «die Arbeit», «die Stelle», «der Job». Под карточкой мягкая подсказка: «Подробный разбор с грамматикой A1–B2 и
  нейросетями — после бесплатной регистрации» (ссылка на `/profile`). Без навязчивости.
- Кэш словарей — как сейчас (D1). Файлы `functions/_lib/dict/*`; новый файл — `wiktionaryRu.ts`.
