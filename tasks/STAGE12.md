# Задание: этап 12 — полноценное Android-приложение (не «сайт в рамке»)

Можно делать до или после этапа 11 — версию возьми следующую после текущей в `package.json`
(минорная +1, например 0.13.0 → 0.14.0), `versionCode` в `android/app/build.gradle` +1.
Сначала прочитай `HANDOFF.md` (журнал: записи Claude 0.11.0–0.12.2 — как сейчас устроено приложение),
`AGENTS.md`, `tasks/APPS-NOTES.md`.

**Слова владельца:** «Приложение — полная ерунда, это просто веб-браузер, свёрнутый в приложение. Нужно сделать
полноценное приложение, не как браузер. Браузерная версия (сайт) пусть остаётся как есть».

**Сейчас:** `capacitor.config.ts` → `server.url` = сайт: приложение просто открывает yai-translator.pages.dev.
Обновляется само, но выглядит как браузер: веб-меню, выделение текста, «резиновый» скролл, нет переходов,
нет нижних вкладок, без сети — пустой экран.

**Правила этапа (обязательно):**
- Сайт в браузере должен выглядеть и работать **как раньше**. Всё новое — только в приложении
  (`storeBuild() === 'android'`, он уже определяет приложение через `Capacitor.isNativePlatform()`).
- Не сокращай промпты и чужой код ради 250 строк — дели файлы. Имена полей клиент↔сервер проверяй с обеих сторон.
- **Не трогай:** логотип; `functions/**` (кроме, если очень нужно, CORS); `deeplUrl()`; `schemaReady`; `prompts.ts`,
  `promptsPro.ts`; снимок экрана в `useTranslator.ts` (только добавлять); `MainActivity.java` — логику передачи текста
  (`yaiSharedText`) сохранить.
- Пакеты только с `registry.npmjs.org` (`findstr npmmirror package-lock.json` — пусто). Только бесплатное.
- Новые надписи — сразу в три файла `src/locales/*.json`. Без subagent, по шагам. На GitHub ничего не отправляй.

## 1. Экраны внутри APK + обновление «по воздуху» (без браузера)

- Убери `server.url`: приложение снова грузит **встроенную** сборку (`webDir: dist`) — запуск мгновенный, интерфейс
  работает без сети. API — на сайт (`VITE_API_BASE=https://yai-translator.pages.dev`, CORS уже есть, вход —
  заголовок `Authorization`, как в `src/api/request.ts`).
- Самообновление содержимого без нового APK: `@capgo/capacitor-updater` (open-source, **ручной режим без облака
  Capgo**, бесплатно). Скрипт `scripts/build-app-bundle.mjs`: собирает веб-часть с `VITE_STORE_BUILD=android`,
  упаковывает в `dist/app/bundle-<версия>.zip` и пишет `dist/app/bundle.json`
  (`{ "version": "...", "url": "https://yai-translator.pages.dev/app/bundle-<версия>.zip", "minVersionCode": N }`).
  Cloudflare Pages при каждом push собирает и сайт, и этот архив (команда сборки — допиши в отчёт, что поменять
  в настройках Pages, если нужно; лучше — чтобы `npm run build` делал оба).
- В приложении при запуске: проверить `bundle.json` → скачать архив в фоне → применить **при следующем открытии**
  (не перезагружать посреди работы). Если архив сломан — откат на встроенную сборку (`notifyAppReady`).
- Проверка нового APK (`public/version.json`, `src/lib/appUpdate.ts`, окно «Обновить») — оставить.
- Профиль/«Приложения»: «Версия приложения (APK)» и «Версия содержимого» — обе.

## 2. Вид приложения (только Android)

- **Своя оболочка** `src/components/app/AppShell*.tsx`: вместо бокового меню и веб-шапки —
  **нижняя панель вкладок** как в нативных приложениях (Перевод · Словарь · Учёба · Профиль · Ещё), крупный заголовок
  экрана, без футера, баннеров «установите приложение», без ссылок «скачать APK».
- **Переходы между экранами** (сдвиг/затухание 200 мс), без «мигания» всей страницы.
- **Ощущение приложения:** запрет выделения текста в интерфейсе (`user-select: none`, кроме полей ввода, текста
  перевода и карточек слова), без серой подсветки нажатия, без «резинового» скролла (`overscroll-behavior: none`),
  без масштабирования пальцами, без контекстного меню браузера на долгом нажатии по кнопкам.
- **Края экрана:** edge-to-edge, отступы под вырез/статус-бар/жесты (`env(safe-area-inset-*)`), цвет статус-бара
  и нижней системной панели — по теме.
- **Клавиатура:** `@capacitor/keyboard` — экран сжимается, поле ввода не прячется под клавиатурой; кнопка «Готово».
- **Отклик:** `@capacitor/haptics` — лёгкая вибрация при свайпе по истории, добавлении в избранное, смене языков.
- **Нативные функции:** `@capacitor/share` (поделиться текстом и картинкой), `@capacitor/clipboard`
  (кнопка «Вставить» и «Копировать»), озвучка — уже нативная.

## 3. Экран перевода в приложении

- Как в приложении Google/Яндекс Переводчика: сверху переключатель языков (большие кнопки + ⇄), поле ввода на
  всю ширину, ниже — карточка перевода.
- **Свайп по истории понятен:** пока поле пустое — список последних 10 переводов (нажать — открыть) и подсказка
  «Смахните перевод влево/вправо — листать историю» (показать 2 раза, потом скрыть). Свайп работает по карточке
  перевода; при листании — сдвиг карточки за пальцем (а не только после отпускания).
- Полная карточка слова — отдельный экран (шторка снизу на всю высоту) с кнопкой «Назад», а не длинная прокрутка.

## 4. Android TV

- Определить ТВ (нет сенсора / `UiModeManager` через маленький плагин или `navigator.maxTouchPoints === 0` и
  ширина ≥ 960): **левая панель навигации** вместо нижних вкладок, крупный шрифт (×1.25), большой видимый фокус,
  всё доступно стрелками пульта, ввод голосом — кнопка микрофона заметная.

## 5. Без сети

- Интерфейс открывается всегда. История, избранное, карточки и учёба работают офлайн. Перевод без сети —
  понятное сообщение «Нет интернета» с кнопкой «Повторить» (не пустой экран). `public/offline.html` больше не нужен
  для запуска (можно оставить как запасной).
