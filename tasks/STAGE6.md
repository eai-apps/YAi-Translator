## 1. Мои карточки (колода)

- В карточке слова (`WordCard`, `DictCard`) — кнопка **«+ В карточки»** (иконка-закладка). Повторное нажатие — «Убрать из карточек».
  В строке перевода для 1–3 слов — та же кнопка рядом со звёздочкой «Избранное».
- Карточка хранит снимок: `{ id, lemma, lang:'de', article|null, plural|null, partOfSpeech, translations[] (до 3, на языке
  перевода), example {text, translation}|null, perfekt|null (для глаголов: «hat gearbeitet»), addedAt, updatedAt }`.
  Данные берутся из уже загруженной карточки слова — **новых запросов к ИИ нет**.
- Хранение: `localStorage` (с try/catch), у вошедших — синхронизация с аккаунтом по образцу `api/sync.ts`
  (новая таблица `study_cards` и `study_progress`, побеждает запись с большим `updatedAt`, лимит 3000 карточек на аккаунт).
- Кнопка **«Добавить из избранного»**: все избранные слова (1–3 слова) одним нажатием. Для слов без снимка карточка
  догружается через `/api/word` (ответ сервера из кэша) — по одному, с паузой 300 мс, с индикатором «5 из 20».

## 2. Готовые наборы для старта

- Файлы `shared/decks/a1-*.ts` и `a2-*.ts`: **8 наборов по 15–20 слов** (A1: семья, еда, дом, город и транспорт, работа,
  время и дни; A2: здоровье, покупки). У каждого слова: lemma, article, plural, partOfSpeech, перевод ru/uk/en,
  простой пример с переводом на ru.
- **Только проверенные данные:** артикль и множественное число бери из Wiktionary (de.wiktionary.org), не по памяти.
  Если не уверен в слове — не включай его.
- Экран «Наборы»: название, уровень, число слов, кнопка «Добавить в мои карточки».

## 3. Повторение (интервалы)

- Алгоритм SM-2 упрощённый: оценки **«Не помню» / «Трудно» / «Помню» / «Легко»**; интервалы 1 → 3 → 7 → 16 → 35 дней…
  «Не помню» — карточка снова сегодня в конце сессии. Прогресс — `study_progress {cardId, ease, interval, due, reps, lapses}`.
- Сессия: до 20 карточек «на сегодня» (сначала просроченные, потом новые, новых не больше 10 в день — настройка).
- Лицевая сторона: немецкое слово **с артиклем цветом** (der синий, die красный, das зелёный), кнопка «озвучить»
  (`useSpeech`). Оборот: перевод, мн. число, пример. Переворот по нажатию, плавно (CSS transform, без библиотек).
- Режим «наоборот» (русский → немецкий) — переключатель вверху сессии.

## 4. Упражнения (всё из карточек, без ИИ)

Экран «Упражнения», каждое — 10 вопросов, в конце итог и «Ещё раз»:
1. **Артикль:** «___ Tisch» → der / die / das (только существительные).
2. **Множественное число:** выбор из 4 вариантов (правильный + 3 неверных формы, построенных по правилам: -e, -en, -er, умлаут).
3. **Перевод:** слово → 4 варианта перевода (неверные — переводы других карточек).
4. **Аудирование:** звучит слово (TTS) → напиши его. Проверка без учёта регистра; умлауты можно `ae/oe/ue/ss`,
   тогда «Правильно, но пишется Bäcker».
5. **Собери предложение:** пример из карточки разбит на слова, перемешан → нажимай по порядку.
- Если подходящих карточек меньше 4 — упражнение показывает «Добавьте ещё N слов» и ссылку на «Наборы».
- Ответы влияют на интервалы как оценка «Помню» / «Не помню».

## 5. Слово дня и серия

- **Слово дня:** одно на всех на день, выбирается сервером детерминированно из готовых наборов (`hash(дата) % N`),
  `GET /api/word-of-day` (кэш до конца дня по UTC). Карточка на экране «Учёба» и на «Перевод» под пустым полем
  (маленькая, можно скрыть крестиком до завтра). Кнопки «Перевести» (подставляет в поле) и «+ В карточки».
- **Серия дней:** день засчитан, если повторено ≥ 10 карточек или сделано 1 упражнение. Цель дня (10 / 20 / 30) — настройка.
  Огонёк и число дней вверху «Учёбы». Хранится локально и в аккаунте.

## 6. Экран «Учёба»

Сверху вниз: серия и цель дня (кольцо прогресса, SVG) → кнопка **«Повторить (N)»** → слово дня → плитки
«Упражнения», «Мои карточки (N)», «Наборы», «Грамматика» (ссылка на `/grammar`) → статистика за 7 дней
(столбики SVG: сколько карточек повторено). Маршруты: `/learn`, `/learn/review`, `/learn/cards`, `/learn/decks`,
`/learn/practice/:type`. Ленивая загрузка (`React.lazy`) как у админки.

- «Мои карточки»: список с поиском, фильтр «на сегодня / все / трудные», удалить, открыть в переводчике.
- Экспорт: **CSV** и **Anki** (текстовый файл «слово;перевод», с артиклем) — кнопки в «Мои карточки».
