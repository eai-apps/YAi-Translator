## 1. Своя база немецких слов (статические файлы, без сервера)

Скрипт `scripts/build-lexicon.mjs` (Node, запускается вручную один раз; результат кладётся в репозиторий):
- **Существительные:** `github.com/gambolputty/german-nouns` (CSV из Викисловаря, CC BY-SA): род, мн. число, 4 падежа ед./мн.
- **Глаголы, прилагательные, транскрипция:** выгрузка Викисловаря от kaikki.org (wiktextract, немецкий, JSONL):
  Präsens 3 л., Präteritum, Partizip II, вспомогательный глагол, степени сравнения, IPA. Брать только нужные поля.
- **Частотность:** список частотных немецких слов (например, `github.com/hermitdave/FrequencyWords`, `de_50k`) —
  оставить **~30 000** самых частых лемм (и их формы → ссылка на лемму, чтобы «geholt» находил «holen»).
- Результат: `public/lex/de/<первые 2 буквы>.json` (нижний регистр, умлауты как есть), записи компактные:
  `{ "Tisch": { "g": "der", "pl": "Tische", "gen": "Tisches", "ipa": "tɪʃ", "pos": "n" }, "holen": { "pos": "v",
  "p3": "holt", "prt": "holte", "p2": "geholt", "aux": "haben", "ipa": "ˈhoːlən" }, "geholt": { "lemma": "holen" } }`.
  Общий размер ≤ 25 МБ, один файл ≤ 1 МБ. Файл `public/lex/de/meta.json` — версия, дата, источники, лицензии.
- Для русских слов (ru → de) — то же из ru.wiktionary, только если есть готовая выгрузка со свободной лицензией
  (kaikki/wiktextract для русского раздела); если нет — пропустить и написать в отчёте.

## 2. Клиент: мгновенный заголовок карточки

- Хук `src/hooks/useLexicon.ts`: по слову грузит нужный файл `/lex/de/xx.json` (кэш в памяти + service worker кэширует
  как статику), отдаёт запись за ~50 мс.
- В карточке слова (`WordCard`/`WordPanel`) и в карточке словарей для гостей: пока ИИ думает — сразу показать
  **артикль цветом, слово, транскрипцию, мн. число / формы глагола** из базы и строку «Подробный разбор готовится…».
  Когда приходит карточка ИИ — она заменяет заготовку без прыжков вёрстки.
- Без ИИ (гость, лимит) — база + словари (Wiktionary, Tatoeba) дают полноценную карточку.

## 3. «Прогрев» популярных карточек ИИ (готовы заранее для всех)

- `POST /api/admin/warm` (только с секретом `WARM_TOKEN` в заголовке `Authorization: Bearer …`): берёт следующие
  N слов (по умолчанию 40) из списка `scripts/warm-words.txt` (≈3000 слов A1–B2 из частотного списка, по одному в
  строке), для каждого вызывает тот же код, что `/api/word` (ru→de и de→ru), **только бесплатные ключи сайта**,
  пишет в обычный кэш карточек. Прогресс (номер строки) — в `settings`. Уже готовые карточки пропускать.
- `.github/workflows/warm-cards.yml`: по расписанию раз в сутки ночью (cron) и вручную — `curl` к этому адресу
  с секретом `WARM_TOKEN`. Секрет создаст Claude (на GitHub и в Cloudflare) — напиши в отчёте, что нужно.
- В админке → «Обзор»: «Готовых карточек: X из 3000».
