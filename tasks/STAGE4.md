# Задание: этап 4 — словари «как Leo» и полезные ресурсы (версия 0.5.0)

Делать **только после того, как Claude проверил этап 3.** Сначала прочитай `AGENTS.md` и `REPORT.md`.

Цель: карточка слова опирается не только на ИИ, а на **настоящие словарные базы** (как Leo, Duden, Wiktionary),
работает и без ИИ, и показывает, откуда взяты данные. ИИ остаётся для объяснений и примеров.

## 1. Источники (один файл = один источник, папка `functions/_lib/dict/`)

| Файл | Источник | Что даёт | Ключ |
|---|---|---|---|
| `wiktionary.ts` | Wiktionary REST: `https://en.wiktionary.org/api/rest_v1/page/definition/{слово}` и `https://de.wiktionary.org/api/rest_v1/page/html/{слово}` | значения, часть речи, род, формы, для всех 12 языков | не нужен |
| `openthesaurus.ts` | OpenThesaurus: `https://www.openthesaurus.de/synonyme/search?q={слово}&format=application/json` | немецкие синонимы и близкие слова | не нужен |
| `tatoeba.ts` | Tatoeba API v1: `https://api.tatoeba.org/v1/sentences` (параметры смотри в `https://api.tatoeba.org/openapi.json`) | настоящие примеры предложений с переводом от людей | не нужен |
| `pons.ts` | PONS API (1000 запросов в месяц бесплатно после регистрации) | словарная статья DE↔RU/EN и др. | `PONS_API_KEY`, необязательный |

Правила:
- **OpenThesaurus требует:** ссылку на www.openthesaurus.de (без `nofollow`) на странице «О приложении» и контакт
  в заголовке `User-Agent` каждого запроса: `YAi-Translator/0.5 (+https://yai-translator.pages.dev/about)`.
  Не больше 60 запросов в минуту — поэтому всё кэшируется в D1 на 30 дней.
- Tatoeba — лицензия CC BY 2.0 FR: у каждого примера показывай «Tatoeba» и ссылку на предложение.
- Wiktionary — CC BY-SA: подпись «Wiktionary» со ссылкой на статью.
- Если API источника не отвечает или формат не совпадает с документацией — источник молча пропускается,
  в `REPORT.md` пишешь, что именно не сработало. **Не выдумывай поля и адреса.**
- Leo, Duden, dict.cc, Reverso: открытого API нет, данные копировать запрещено — **не подключать**.

## 2. Как это собирается в карточку слова

- Новый эндпоинт `POST /api/dict {word, sourceLang, targetLang}` → объект `DictEntry`:
  `{ sources: [{id, name, url}], senses: [...], gender, plural, forms: [...], synonyms: [...], examples: [{text, translation, source, url}] }`.
  Источники опрашиваются параллельно (таймаут 6 с каждый), результат кэшируется в D1 на 30 дней.
- Фронтенд: для 1–3 слов `/api/dict` грузится **вместе** с `/api/word`.
  - Если `/api/word` (ИИ) ответил — карточка как сейчас, но синонимы дополняются из OpenThesaurus,
    а к примерам A2/B1/B2 добавляется вкладка **«Из жизни»** с примерами Tatoeba.
  - Если ИИ недоступен (лимит) — карточка строится **только из словарей**: значения, род, формы, синонимы,
    примеры. Пометка «Без ИИ — данные словарей».
- Внизу карточки — строка «Источники: Wiktionary · OpenThesaurus · Tatoeba · PONS» со ссылками.

## 3. Полезные ресурсы

- Страница `/resources` (ссылка в боковом меню и в профиле): для каждого языка — проверенные бесплатные ресурсы
  по группам: «Словари», «Грамматика», «Аудирование и подкасты», «Экзамены», «Жизнь в Германии».
- Данные — таблица D1 `resources(id, lang, category, title, url, description_ru, description_de, description_en, sort, hidden)`.
  Начальный набор (10–20 ссылок для немецкого, по 3–5 для остальных языков) — в `migrations/0004_resources.sql`.
  Только официальные и известные бесплатные сайты (например, DW Learn German, Goethe-Institut, DWDS, Duden онлайн,
  Wiktionary). Каждую ссылку проверь, что она открывается.
- В админке — вкладка «Ресурсы»: добавить, изменить, скрыть, поменять порядок.
- Переключатель в админке «Показывать ресурсы в приложениях из магазинов» (для будущих версий App Store / Google Play).
